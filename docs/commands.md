# Команды на каждый день

Большую часть делает сайт банка идей: http://localhost:8777. Если он не открывается, запусти Claude в папке `scenarios` и напиши «запусти bank.py в фоне».

Для остального открываешь Claude в папке `scenarios` (`cd ~/scenarios`, потом `claude`) и пишешь обычными словами.

---

## На сайте

| Хочу | Где |
|---|---|
| Посмотреть все идеи | вкладка «Идеи» |
| Сценарий по конкретной идее | карточка идеи → «Написать сценарий» |
| Убрать неподходящую идею | карточка → «Убрать» |
| Найти новых блогеров | кнопка «Найти блогеров» → вкладка «Блогеры» → «В разведку» |
| Собрать залёты прямо сейчас | кнопка «Собрать залёты» |
| Что система делала ночью | вкладка «Журнал» |

## Работа со сценарием

**Переписать хук**
```
Сценарий scripts/<файл>. Дай 5 вариантов хука по правилам из knowledge/rules.md, раздел 3. Каждый про зрителя. Рядом с каждым – что на экране в первую секунду.
```

**Сделать короче**
```
Сократи сценарий scripts/<файл> до 40 секунд. Хук и вывод не трогай, режь воду в середине.
```

**Звучит не как я**
```
Перепиши сценарий scripts/<файл> моими словами по knowledge/style.md. Сверь с цитатами-образцами. Смысл не меняй.
```

**Проверить свой сценарий**
```
Проверь этот сценарий строго по knowledge/check.md и knowledge/rules.md:
<вставь текст>
```

**Сценарий по любому чужому ролику**
```
Напиши сценарий по этому рилсу: python3 write.py --id <ссылка на рилс>
```

## Настройка

**Поправить паспорт или стиль**
```
Открой knowledge/passport.md. Поменяй: <что поменять>.
```

**Добавить или убрать блогера**
```
Добавь в bloggers.txt: <ник>. Собери его ролики сейчас: python3 collect.py <ник>
```

**Залёт – не ×2, а ×3** (если залётов слишком много)
```
В config.py поставь OUTLIER_X = 3.0
```

**Сценарии на Opus** (если подписка Max)
```
Допиши в .env строку WRITE_MODEL=opus
```

## Если что-то сломалось

**Утром не пришли сценарии**
```
Сегодня утром сценарии не пришли. Запусти doctor.py, посмотри журнал за сегодня в logs, найди причину и почини.
```

**Instagram просит войти**
```
Запусти login.py, я войду сам.
```

Если Instagram просит подтверждение или ограничил аккаунт – пройди проверку и не запускай сбор 1–2 дня. Полистай ленту с этого аккаунта с телефона.
