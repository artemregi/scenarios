# Домашка к уроку 2

Срок – до следующего урока. Результат присылай в чат.

## 1. Система работает сама · 3 утра подряд
- [ ] Каждое утро в Telegram приходят сценарии.
- [ ] Если не пришли – сначала попроси Claude найти причину (команда в [docs/commands.md](commands.md)), потом пиши в чат.

## 2. Расширь разведку
- [ ] Доведи список до 10 блогеров.
- [ ] Минимум 3 из них – с аудиторией, похожей на твою по размеру.

## 3. Выбери и доведи один сценарий
- [ ] Из всех пришедших выбери один, который хочется снять.
- [ ] Пройди его по чек-листу [docs/checklist.md](checklist.md) сам, руками.
- [ ] Поправь хук: дай Claude команду «5 вариантов хука» и выбери лучший.
- [ ] Прочитай вслух. Где спотыкаешься – там не твои слова, правь.

## 4. Сними ролик
- [ ] Сними и выложи этот ролик.
- [ ] Через 2 дня пришли в чат: ссылку на ролик, ссылку на оригинал, просмотры и сколько процентов досмотрели первые 3 секунды (статистика ролика в Instagram).

## Что прислать в чат
1. Скриншот утреннего сообщения со сценарием.
2. Финальный текст сценария.
3. Ссылка на свой ролик и цифры из пункта 4.
